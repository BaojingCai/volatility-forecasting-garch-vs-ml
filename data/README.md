# Data

The raw data behind this project comes from the **VOLARE high-frequency financial
database** and is **not redistributed here** — it is a licensed source. This directory
holds only the documentation needed to reproduce the inputs.

## What the pipeline expects

```
data/
├── raw/
│   └── realized_var_stocks.csv    <- VOLARE extract (not in this repo)
└── processed/
    └── rv_features_created.xlsx   <- generated by notebooks/2_feature_engineering.ipynb
```

`realized_var_stocks.csv` is a VOLARE "STOCKS / VOLATILITY" extract covering
2015-01-02 to 2026-03-31. The download used here contains 113,080 records across 40
tickers and 35 columns; the pipeline filters it down to the six stocks listed in
`config.py`.

Columns actually consumed:

| Column | Use |
|---|---|
| `rv5` | Realized variance from 5-minute returns — the forecast target |
| `open`, `close` | Open-to-close log return `ret`, used for the leverage terms |
| ticker, date | Filtering and indexing |

`readme_var.txt` is the manifest VOLARE emits with the download and lists every
realized-variance measure available in the extract.

## Obtaining the data

VOLARE is accessible through an institutional subscription. Any realized-variance
dataset with the columns above can be substituted — adjust the loader in
`notebooks/2_feature_engineering.ipynb` and the ticker list in `config.py`.

`processed/rv_features_created.xlsx` is fully derived, so it is not committed either.
Running `2_feature_engineering.ipynb` regenerates it from the raw extract.

## What *is* committed

Everything downstream of the data: all model code, the complete set of out-of-sample
forecasts (`results/forecasts/`), per-model metrics, parameter paths, the thesis tables
and all twelve figures. The reported results can be checked without access to VOLARE.
